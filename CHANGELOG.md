# Changelog

All notable project changes are documented here.

## 0.1.0 - 2026-08-03

- Added an installable `src`-layout Python package and command-line interface.
- Added deterministic N-1 and seeded random multi-fault generation.
- Made random scenarios fully replayable through `failures_json`.
- Preserved parallel branches and emitted bidirectional PyG edges.
- Added a direct NPZ loader, deterministic data split, training-only normalization,
  and self-describing checkpoints.
- Added tests, continuous integration, citation metadata, and reproducibility docs.
