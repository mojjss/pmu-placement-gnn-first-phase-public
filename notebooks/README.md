# Historical notebooks

These notebooks preserve the original exploratory sessions and rendered outputs.
They are not the canonical source for new runs.

- `Greedy-1.5*.ipynb`: graph construction, greedy labels, fault analysis, and
  early NPZ export.
- `GNN-1.5.ipynb`: early GCN workflow.
- `GNN-1.7-IEEE*.ipynb`: later system-specific training and evaluation sessions.

Use `src/pmu_placement_gnn/` for portable paths, replayable multi-fault scenarios,
parallel branches, bidirectional PyG edges, deterministic splits, and reusable
entry points. See [NOTEBOOK_MAP.md](../docs/NOTEBOOK_MAP.md).

Stored execution counts describe the original sessions only. They are not a
claim that every notebook was re-executed in the current environment.
